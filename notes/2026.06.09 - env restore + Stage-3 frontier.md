# 2026.06.09 — Environment restore (C:\tmp\bc45 wiped) + Stage-3 frontier

## Environment regression (FIXED)

On resume, closure measurement collapsed: railc 3/20, OWL 0. Root cause:
**`C:\tmp\bc45` had been deleted** (C:\tmp is volatile temp; it got cleaned
between sessions). The GOAL doc + every script reference `C:\tmp\bc45\{INCLUDE,
SOURCE,BIN,LIB}`. With that path gone, `bcc.exe`'s `SearchPathResolver` found
nothing in the (nonexistent) `-I C:/tmp/bc45/INCLUDE` and fell back to
`DefaultResolver`, which **stubs unknown system headers to empty** — so OWL/RTL
headers silently vanished and `BOOL`/`size_t` were undefined (`ctl3d.h:57`).

**Fix:** recreated `C:\tmp\bc45` as a **directory junction → `C:\mdtmp\BC45`**
(the stable master Borland install; identical to `wrk_oracle\bc452\BC45`,
166 MB, BCC32/TLINK/BRC + full INCLUDE/SOURCE/LIB). Junction = zero-copy, the
canonical path works, read-only consumption only.

    New-Item -ItemType Junction -Path C:\tmp\bc45 -Target C:\mdtmp\BC45

**If closure ever collapses to ~stub-header errors again, recreate the junction.**

After restore: railc **19/20** (LAYOUT.CPP = Stage-3 fstream), OWL **90**,
closure back to the true **30** unresolved.
