## Caveats

The GUI parity result is sampled coverage, not exhaustive proof of every menu item, toolbar path, help path, modal dialog, and full real-time playthrough.

The Set data file select-success path remains parked. The harness can verify cancel behavior and can verify alternate data files through seeded `RC.INI`, but current automation could not make the Windows common dialog return a successful `GetOpenFileNameA` selection. Golden and mdbcc behaved identically under the failed automation, so this is an oracle limitation rather than a known compiler mismatch.

The release/full-suite GUI failures seen before Step 2 were scheduler/isolation flakes in the test harness. The committed GUI mutex now serializes true interactive GUI runtime probes while leaving non-interactive launch tests parallel.
