## G2 — free/friend operator fallback (de0fc8d)

C++ [over.match.oper] builds one candidate set from member AND non-member
operators; mdbcc committed to member-only whenever the LHS class declared any
member `operator@` and hard-errored when none was viable (`is >> setw(4)`:
istream's member `>>`s all reject smanip — only IOMANIP.H's friend matches).
Three coordinated changes: gen_binary member-fail→free fallback
(`free_binop_candidate` split), the same fallthrough in expr_type's Binary arm
(chain typing), and a gen_ref_arg fix for chained ref-returning operator args —
the old path materialized the returned ADDRESS into a temp and passed the
temp's address (phantom `T&&`): `s << 5 << m` mutated a phantom object
(mdbcc 12 vs bcc32 42, oracle-verified).
**STRINGIO.CPP now compiles — the RTL string family (railc `string` closure
slice) is complete.** DATEIO/TIMEIO advance to their true Stage-3 blocker
(ostrstream construction).

## G4 slice 1 — closer-base overload ranking (8249805)

Derived-to-base reference bindings scored a flat 3 → two viable base-ref
candidates always tied. `SuspendThrow(x)` (x: TXOwl&; TXBase& at 1 hop vs

## The convergence: G5 is now THE OWL gate

With G4 fixed, **WINDOW.CPP fails only on multi-try i386 EH**
(`TWindow::ReceiveMessage`: 6 `try` blocks) — exactly APPLICAT.CPP's blocker
(`TApplication::Run`: 4). One feature unblocks TWindow + TApplication — the
heart of W4 and railc's window machinery.

**G5 design sketch (for its own fresh arc — EH is never rushed at depth,
b12):** the S2e fs:[0] registration carries ONE late-bound catch-pad imm32
(`seh_pad_patch`, codegen.rs ~3165). Multi-try needs the standard SEH3 shape:
a per-function SCOPE TABLE in .rdata (N entries: pad offset (+ policy)) and a
frame TRYLEVEL slot — body writes level i on try-entry, -1 on exit; the
module handler (`.mdbcc_seh3_handler`, eh.rs) reads trylevel from the
registered frame and indexes the table instead of the single pad. Sequential
(non-nested) trys are the OWL shape and the v1 target; nesting = enclosing-
level chain in the same table. Touches: frame layout, prologue record,
try-entry/exit codegen, both module handlers, the cleanup-scope variant.
