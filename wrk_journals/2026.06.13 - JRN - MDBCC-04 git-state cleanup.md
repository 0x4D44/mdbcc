# JRN — MDBCC-04: loose git-state cleanup (stale mdrc worktree + factcheck stash)

**Date:** 2026-06-13
**Issue:** MDBCC-04 (daily status §6/§10/§12-1) — a 20-commits-behind worktree
carrying an uncommitted `mdrc` resource-compiler build-out, plus an overlapping

preserve everything else recoverably, then drop the loose state.

## Why park, not land (verified)

`main`'s W5 (`ad7a6bc`) + W6 (`b188eb6`) **independently rebuilt** `src/rc`
(+2000/−257) and added committed `src/bin/mdrc.rs` + `src/rc/pp.rs`. Verification
(3 parallel investigators + adversarial verifier) found:

- **Source/preprocessor:** `main` equals or exceeds the worktree at every level —
  full resource-type parity, both `write_res`/`write_res_bc45` profiles, the style
  table, the `#define/#include/#ifdef` preprocessor (`pp.rs` vs the worktree's
  `preprocess.rs`). The same PE32 DataDirectory fix is already on `main`, verbatim.
- **Regression hazard:** the worktree's `pe_unsupported_reason` guard would *reject*
  resources `main` already emits — landing it is a regression, not a gain.
- **Stash:** strictly contained in `main` — its code still errors on gaps 7–10 that
  `main` implements; its WIP journal is a 9-line prefix of `main`'s committed
  651-line `wrk_journals/2026.06.10 - JRN - rc compiler continuation.md`.
- **The one unique artifact:** the worktree's untracked `tests/rc_railc.rs` — a
  byte-identical golden acceptance oracle for the real `RAILC.RC` vs the BC4.5
  golden `wrk_oracle/railc_golden/railc.res`. `main` had **no equivalent**
  (its rc tests are per-feature/synthetic, or use `railc.res` only as a link input).

Landing the build-out = an "on-ramp to nowhere" (zero new capability + a regression).

## Actions taken

1. **Salvaged** `tests/rc_railc.rs` onto `main` — ported verbatim except the
   `compile_file` defines arg (`&[]` → `&HashMap::new()`, to match `main`'s
   `compile_file(path, &HashMap<String,String>)`). Runs green:
   `railc_rc_matches_golden_res ... ok` — proving `main`'s `mdrc` is byte-identical
   to the BC4.5 golden on the real 75 KB `RAILC.RC`.
   - Golden kept **gitignored** (decision): the oracle runs wherever the golden +
     railc corpus exist (like `main`'s other railc tests) and skips gracefully
     elsewhere. No repo-policy change.
2. **Preserved** the worktree's full uncommitted state as commit `cd01ced` on branch
   `worktree-wf_5a36b7a6-b30-2` (now 1 ahead of `main`). The branch ref persists
   after worktree removal — nothing lost.
3. **Exported** the stash's tracked diff to `wrk_journals/mdbcc-04-factcheck-stash.patch`
   (safety net; the stash is fully superseded by `main` anyway).
4. **Removed** the stale worktree directory `.claude/worktrees/wf_5a36b7a6-b30-2`.
5. **Dropped** `stash@{0}` (factcheck-temp-stash).
