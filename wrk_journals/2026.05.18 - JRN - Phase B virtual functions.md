## Phase B design (from HLD, grounded in code)
- Polymorphic iff class/base declares any `virtual` (incl. vdtor).
- vptr @ offset 0 (8B); shift data members +8; single-inh
  base-at-0 reuses ONE vptr (base-flatten must not duplicate).
  Non-polymorphic classes unchanged ⇒ O1 88 byte-identical
  (same regression argument as Phase A).
- Per-class vtable: base virtuals (decl order) then new
  virtuals; override replaces inherited slot. Read-only global
  of 8B slots, each a `RipRef::Func` (reuse Phase A). ctor:
  after base-ctor chain, `lea rax,[rip+vtbl]; mov [this+0],rax`.
- Virtual call: `mov rax,[this]; mov rax,[rax+slot*8]; call rax`
  — reuse Phase A indirect marshalling, callee from vtable.
  Non-virtual stays direct `call Tag::m`.
- Virtual dtor: takes a slot; `delete p` w/ virtual dtor
  dispatches through vptr (Derived::~ then base chain).
- Pure `=0` ⇒ abstract: instantiation = clear CodegenError;
  slot → "pure virtual called" trap stub.
- Deferred (explicit): MI/virtual inh, RTTI/dynamic_cast,
  covariant returns, this-adjusting thunks.
