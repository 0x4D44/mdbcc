### Session 1c supervisor decisions

**Decision-1c.1 — Override HLD §5.6 two-function recommendation.**

The HLD §5.6 said "Each writer is its own function ... Trying to
parametrise one function would yield uglier code than two parallel
functions" — but that was a pre-implementation intuition. Looking
at the actual `write_pe32plus_from_objects` body (~1230 LoC,
lines 1899-3129), the PE32 vs PE32+ divergence is bounded to ~30
lines of optional-header emission. Copy-paste-with-tweaks would
duplicate ~1200 lines for no real benefit and create drift risk.

Parametrising over machine width = ~30 lines of branches inside
one function vs ~1200 lines duplicated. Maintenance-easier;
less drift risk. **Overriding HLD §5.6**; rationale recorded
here so future readers know why the impl diverged from spec.

Mechanics: drop the dispatch wrapper the S2d agent added (the new
`write_pe_from_objects` that calls `write_pe32plus_from_objects`
or `write_pe32_from_objects`). Keep the rename UNDONE — restore
the original name `write_pe_from_objects`. Branch on
`opts.machine` inside the unified function at the divergence
points. Keep the width-parameterised `emit_idata_with_thunk`
that S2d added (that part of S2d's work survives).

**Decision-1c.2 — S2b deferred until Jun 2 agent budget reset.**
