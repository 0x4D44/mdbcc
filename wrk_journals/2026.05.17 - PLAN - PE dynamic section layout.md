## §1 Defect anatomy (all in src/pe.rs)
Fixed 4 KB RVA assumption baked in via 4 constants used pervasively:
- TEXT_RVA=0x1000/IDATA_RVA=0x2000/RDATA_RVA=0x3000/DATA_RVA=0x4000 — fixed
  0x1000 spacing; any section image >0x1000 overlaps next.
- build_idata `rva = |off| IDATA_RVA+off` — IAT/ILT/descriptor/name RVAs.
- iat_rva/import_dir_rva fixed → optional-header data dirs [1] Import, [12] IAT.
- build_rdata `RDATA_RVA+image.len()` — string-literal RVAs (RIP targets).
- build_data `DATA_RVA+`, `RDATA_RVA+`, `IMAGE_BASE+str_rva` — globals + the
  absolute pointer-to-string value stored in .data bytes.
- build_text stub disp uses fixed TEXT_RVA; `next_rva=TEXT_RVA+site+4` (all
  RIP fixups).
- size_of_image = align_up(DATA_RVA+data_vsize, SECT_ALIGN) — undersized
  whenever any earlier section >0x1000.
- AddressOfEntryPoint/BaseOfCode = TEXT_RVA; 4 section-header VAs hard-coded.
- module doc comment stale.
Invariants violated: per-section VA=align_up(prev.VA+prev.VSize,SECT_ALIGN);
SizeOfImage=align_up(last.VA+last.VSize,SECT_ALIGN); file offsets independent
align_up(_,FILE_ALIGN) from SizeOfHeaders. Headers/HEADERS_SIZE already
size-independent — no change.

## §2 Target design
Build each section image base-relative (offset 0), compute layout from
sizes, add each base RVA exactly where an absolute RVA is needed. Section
order UNCHANGED (.text,.idata,.rdata,.data). Linear pass (no circularity):
text_vsize pre-pass = STUB_LEN+Σf.code.len() → text_rva=align_up(
HEADERS_SIZE,SECT_ALIGN)=0x1000 → idata_rva=align_up(text_rva+text_vsize,
SECT_ALIGN) → build_idata(idata_rva) → rdata_rva → build_rdata (offsets,
caller rebases) → data_rva → build_data (offsets + correct abs ptr =
IMAGE_BASE+rdata_rva+off) → build_text(...,text_rva) → size_of_image=
align_up(data_rva+data_vsize,SECT_ALIGN). align_up reused as-is (div_ceil;
align_up(0x2000,0x1000)==0x2000). File-offset/SizeOfRawData/FILE_ALIGN/
headers UNTOUCHED. Optional Layout struct; pass &Layout to build_text if
clippy::too_many_arguments trips. Preserve empty-section push(0) guard
placement. Update module doc. Add debug_assert text.len()==text_vsize.
