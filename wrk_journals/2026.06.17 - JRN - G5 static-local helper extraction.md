# 2026.06.17 - JRN - G5 static-local helper extraction

## Context

G5 needs the first structural extraction from `src/codegen.rs` after the active
correctness/performance work is landed. I chose the static-local helper cluster
because it is coherent, small, and covered by existing static-local tests:

- module-global symbol naming for static locals;
- guard-global symbol/key naming for runtime-initialized static locals;
- recursive collection of static-local declarations before function emission.

This is intentionally lower risk than moving ABI or EH lowering first.

## Change

Added `src/codegen/statics.rs` and moved:

- `static_local_symbol`;
- `static_guard_symbol`;
- `static_guard_key`;
- `collect_static_locals`.

`src/codegen.rs` now imports those helpers through the private `statics`
submodule. No logic changed; this is a module-boundary extraction.

Version moved from `0.7.5` to `0.7.6` because source changed.
