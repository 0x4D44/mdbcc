## Gotcha logged: perl on Windows flips LF→CRLF

`perl -0pi -e` (used to strip the temp VTDBG instrumentation) rewrote codegen.rs
from the repo's LF to CRLF → `git diff` showed ~13 700 phantom line changes. Fixed
with a binary `replace(b'\r\n', b'\n')` via python. **Lesson: never use Windows
`perl -i` on LF source — it text-mode-translates the whole file.** Prefer the Edit
tool or python binary I/O for mechanical edits.
