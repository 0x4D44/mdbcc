## G25 (f3e3b88) — linker-level garbage collection

`compute_dead_relocs()` in `src/link/pe_writer.rs`:
- A "unit" = the code/data owned by one defined symbol (its `[value, next
  symbol)` byte range within a section).
- Roots = every unit of every EXPLICIT (non-archive) object (railc's own
  objects link whole; only archive members are GC'd).
- Edges = each relocation → the unit defining its target (intra-object `Section`
  symbols directly; cross-object externals via the `global` table; data units
  like vtables included, so virtual methods stay reachable).
- BFS closure → reachable units. A relocation in an unreachable ARCHIVE unit is
  "dead"; `apply_relocs_multi` skips it in the undefined branch, so it no longer
  demands resolution.

**Pure linker analysis — no codegen / .o-layout change**, so the `.obj`↔bcc32
byte-identity oracle is preserved. All-explicit links (single object, the whole
existing test corpus) get an EMPTY dead set → byte-for-byte unchanged.
