## Feature
`src/pe.rs` hard-codes section RVAs at fixed 0x1000 spacing
(`TEXT_RVA=0x1000, IDATA_RVA=0x2000, RDATA_RVA=0x3000,
DATA_RVA=0x4000`) and computes `SizeOfImage` on that assumption.
Any section > 4 KB overlaps the next ⇒ STATUS_INVALID_IMAGE_FORMAT.
Goal: dynamic section layout (each section placed at
align_up(prev_end, SECT_ALIGN)), correct SizeOfImage, all RVA / reloc
/ import math threaded through, PE stays valid + byte-deterministic.
