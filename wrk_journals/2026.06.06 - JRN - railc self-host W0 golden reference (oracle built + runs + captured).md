## Reproducible recipe (the oracle build)

Tools: `C:/tmp/bc45/BIN/{BCC32,BRC32,TLINK32}.EXE`. Prebuilt libs:
`C:/language/mdbcc/wrk_oracle/bc45/BC45/LIB/`. Invoke bcc/brc/tlink via
`/usr/bin/timeout` (NOT mdtimeout — it mangles bcc args). Output dir:
`C:/language/mdbcc/wrk_oracle/railc_golden/`.

1. **Compile each TU** (from `C:/language/railc`, so quoted includes resolve):
   ```
   BCC32.EXE -c -4 -W -I"C:\tmp\bc45\INCLUDE" -I"C:\language\railc" \
             -n"<golden>" <TU>.CPP
   ```
   TUs (railc.mak order): RAILC DEPARTUR LOCOYARD ARRIVALS FINISH ABOUT STARTUP
   START CONFIGUR LAYOUT SELECTOR PLATFORM TOOLBAR TOOLBUTT STATBAR SECTION
   PLATDATA OVLPDATA ROUTES LOCOS TIMETABL.
   (`-4` = 386 ISA, `-W` = Windows GUI target. PCH/optimization flags from the
   in-tree BccW32.cfg are intentionally dropped — W0 needs a *valid* bcc32 build,
   and parity is judged behaviourally (GUI tiers), not byte-identity to a chosen
   golden image.)
2. **Compile resource** (from `C:/language/railc/RESOURCE`):
   ```
   BRC32.EXE -I"C:\tmp\bc45\INCLUDE" -I"...\RESOURCE" -I"C:\language\railc" \
             -w32 -R -FO"<golden>\railc.res" RAILC.RC
   ```
3. **Link** (TLINK32 crashes on a long command line — MUST use a response file;
   `wrk_oracle/railc_golden/link.rsp` mirrors railc.mak's `@&&|...|` format):
   ```
   TLINK32.EXE @link.rsp     # /v -L<lib> -Tpe -aa -c; c0w32+21 objs; railc.exe,
                             # railc.map; 5 libs; RAILC.DEF; railc.res
   ```
4. **Run sandbox** `wrk_oracle/railc_golden/run/`: copy railc.exe + *.RCD; launch
   with WorkingDirectory = run dir (railc reads RAILC.INI/*.RCD from cwd; never
   write into the read-only railc tree).
5. **Capture** (reusable, used for both golden and mdbcc so shots are diff-able):
   ```
   pwsh wrk_oracle/capture_window.ps1 -Title "Rail Control" -Out <png> -Delay 1
   ```
   (forces the window HWND_TOPMOST at (0,0), then CopyFromScreen of its rect —
   avoids occlusion so the diff is fair.)
