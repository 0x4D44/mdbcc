## The 8 spine increments (commit order)

1. **`dynamic_cast<D*>` i386** (c34ee5f) — byte-additive port of the win64 vtable
   base-chain walk; load-bearing change is the descriptor read `[ecx-4]` (pointer
   width) not `[rcx-8]`. Unblocked the TYPESAFE_DOWNCAST gate on 7 TUs.
2. **float scalar-store width** (7415057) — the float-store lhs-address `mov`
   used raw reg64; one-line `wreg` fix. SECTION, PLATDATA → green.
3. **forward-referenced static data members** (becb069) — C++ complete-class
   context: pre-register a class's own static names up front (token pre-scan) so
   an inline accessor returning a later-declared static resolves (OWL
   `TClipboard::GetClipboard(){return TheClipboard;}`).
4. **const T& binds to a cast rvalue** (db162c3) — gen_ref_arg materializes a
   temp for a prvalue cast (OWL `ToBool((WORD)(...))`), excluding the two
   lvalue-cast forms gen_addr handles.
5. **anon-union scalar init** (3e7a7b8) — `agg.$anon.0 = scalar` descends to the
   union's first member (the OWL response-table entry's `union{Msg;NotifyCode;}`).
6. **per-class member typedefs** (7132e34) — `typedef cls TMyClass;` is a
   class-scoped member typedef re-declared per class; resolve `&TMyClass::method`
   via the enclosing class (`cur_class`), not the flat last-write-wins alias.
   **Compiled the OWL response table end-to-end → 6 TUs green** (LOCOYARD,
   SELECTOR, PLATFORM, TOOLBAR, TOOLBUTT, STATBAR).
7. **by-value record arg via UDC** (22c23e1) — a by-value record param fed a
   non-record arg via a converting ctor (OWL `TDialog(TWindow*, TResId, ...)`
   with a char* name). Resolution (Win32-gated) + i386 cdecl marshal. ABOUT,
   START, CONFIGUR → green.
8. **qualified in-class member defs (ctor + method)** (8897a16) — Borland's
   `Tag::Tag(...)` / `void Tag::method(){}` inside the class body (railc
   LAYOUT.H, RAILC.H's CM_FileExit). RAILC → green.
9. **by-value record arg to a virtual call** (78e0ded) — emit_virtual_call_cdecl
   pushes the struct bytes (cleanup sums push_bytes). DEPARTUR, ARRIVALS → green.
10. **float (4-byte) cdecl arg** (e7f99b2) — cvtsd2ss + 4-byte movss push (the
   ABI-correct single). FINISH, LAYOUT → green. **→ 21/21.**

Each shipped with a focused `tests/i386_run.rs` test (RUN + bcc32 diff): exits

## Deferred / honest gaps (not blockers for W1 compile)

- **f32↔f64 precision**: mdbcc keeps floats as f64 in xmm0; a `float` PARAM read
  inside a mdbcc-compiled callee would need movss + cvtss2sd widen-on-use (the
  F-future polish). Irrelevant to railc (float-arg callees are external/OWL) and
  to W1 compile; a W6 behavioural-parity watch item.
- **dynamic_cast / base@0**: single-inheritance only (shared with win64).
